# Power Flow Card Plus Custom

Custom Home Assistant Lovelace card based on **Power Flow Card Plus** by flixlix.

## Planned v1.0.0 features

- Power mode for live W / kW values.
- Energy mode for cumulative Wh / kWh sensors.
- Energy periods: Today, Yesterday, Week, Month and custom From–To.
- Per-entity deadband / zero tolerance in the graphical editor.
- Per-entity rounding and optional smoothing.
- Grid, Solar, Battery and Individual entities.
- English, Russian and Hebrew UI, including RTL layout for Hebrew.
- Custom card icon.
- HACS-compatible distribution.

## Status

Development branch imported from the current upstream TypeScript source. The custom features are being implemented before the first stable release.
